# Emergency-Room-Dashboard
An interactive Power BI dashboard developed to analyze hospital emergency-room performance, patient flow, waiting times, admissions, referrals, demographics, and patient satisfaction.

# Dashboard Preview
![ER Final Dashboard.pn](https://github.com/akankshapillaii/Emergency-Room-Dashboard/blob/main/ER%20Final%20Dashboard.png)

# Business Problem
Hospital emergency departments handle a large and constantly changing volume of patients. Monitoring patient flow, waiting times, admission rates, referrals, and patient demographics is essential for understanding operational performance.
